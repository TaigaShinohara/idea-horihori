# アイデアホリホリ

アイデアを1行ストックして、AIの質問に答えながら企画メモに育てるアプリ。

- Flutter / Android。アプリのバージョンは `pubspec.yaml` を参照。
- 対応端末ではGemini Nanoを優先する。モデルは設定の「Nanoで質問を試す」から準備できる。
- クラウドのGemini APIは、APIキーを保存してクラウド送信を有効にした場合に利用できる。定型の質問と企画メモは端末だけで使える。
