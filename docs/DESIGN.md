# アイデア深掘りアプリ — 設計 v0.1（2026-11-20）

## 1. コンセプト（本人の言葉が正本）
「アプリのアイデアをストックするアプリ。ボタン一つでAI（API）に深掘りさせる。質問に答えていくことで内容がまとまっていく。」

一言で： **思いつきを、放っておかずに企画に育てる。**

- ひらめきは一瞬で消える → まず1行で捕まえる（速さ）
- ひらめきはそのままでは作れない → AIの質問に答えるだけで企画メモになる（育てる）
- 育った企画は、次のアプリ開発の種になる（大河の量産フローに直結）

## 2. 意味のあるデザイン 3点
1. **何を一番見せたいか**： そのアイデアが「どれだけ育ったか」。タイトルと成長度だけを大きく見せる。
2. **どう思ってほしいか**： 「ただの思いつきが、作れる企画になってきた」ワクワク感。責めない・急かさない。途中で止まっているアイデアも失敗ではない。
3. **効果的な方法か**： 
   - 一覧＝タイトル＋成長バーのみ（minimal information）
   - 深掘り＝質問カードを1枚ずつ（1画面1質問、認知負荷を上げない）
   - まとめ＝決まった型（What / 誰に / なぜ / どうやって / 次の一歩）で自動整理

3点で説明できない要素は入れない／削る。

## 3. アート方針（ART_DIRECTION は別ファイルが正本）
- 質感： Simple Glass 既定。読み物ガラス＝企画メモ面、飾りガラス＝アイデアカード。
- 色の役割： 土台は中立。アクセントは「掘る」行為にだけ使う温かい色1色を軸に、成長度で深まる。
- 形の比喩： 「種 → 芽 → 実」。アイコンと成長バーだけで表し、文字で説明しない。

## 4. コアフロー
1. **ストック**： FAB／下部入力から1行〜短文で登録。即座に一覧へ。タグ・カテゴリは v1 では付けない（入力摩擦ゼロ優先）。
2. **深掘り開始**： カードの［深掘り］ボタン1つ → AIが質問を1つ出す。
3. **Q&Aセッション**： 
   - 1問ずつ表示。回答は「3択チップ＋自由入力」の併用（AIが選択肢を生成、3つ目は広げる選択肢）。
   - 1セッション 5問を目安に自動で区切る（疲れさせない）。途中保存・再開可。
   - 「いったんまとめる」ボタンでいつでも要約生成可。
4. **企画メモ化**： AIが回答群を型に整理 → アイデア詳細に保存。バージョンとして積む（上書きで消さない）。
5. **続きの深掘り**： メモを見ながら「もっと深掘り」で前回の要約を文脈に再開。

## 7. データ
- v1は端末内のみ（ローカル保存）。アカウント・同期なし。
- 1アイデア = { id, title(1行), note(任意短文), createdAt, sessions[], memos[], stage }
- 削除はアーカイブ方式を既定候補（誤削除防止）。確定は実装時に再確認不要の範囲で進める。

## 8. API方針案（→ 本人の判断はボタン1件で別途）
### 推奨： Gemini API ＋ BYOK（利用者自身のキー入力）
- 理由1： 本人の Gemini API 基盤が既にある（ブログ自動化で gemini-4-hydrogen 運用中）。Claude API キーは 2026-11-15 に削除済みで新規発行が必要。
- 理由2： ストア配布時、開発者キー埋め込みは漏洩・課金爆発のリスク。BYOK ならサーバ不要・コストは利用者側・審査も素直。
- 理由3： 質問生成＋要約整理は Gemini で十分な品質帯。日本語も問題なし。

### 代替： Claude API ＋ BYOK
- 長文整理の質は高いが、キー再発行が前提。利用者にも Claude キー取得を強いる形になる。

### 両対応（抽象化）
- profileMaker PoC と同じ AiBackend 抽象化を採用し、Gemini を既定、Claude はアダプタ追加で切替可能に設計する。v1 の実装は Gemini のみ、差し替え口だけ用意。

→ **設計上の結論： 抽象化＋Gemini先行＋BYOK。** 最終選択だけ本人のボタン判断に委ねる。

**決定（2026-11-20 16:39, 本人）： 「1：Gemini＋BYOKで進める」を選択。確定。**

## 9. 技術
- Flutter / Dart、Bundle ID: `com.taigashinohara.<アプリ名小文字>`（アプリ名確定後に固定）
- 署名： プロジェクト `.local/` に専用キーストアを作成し debug/release 共用（既定デバッグ鍵は使わない）
- AI通信： https で Gemini API を直接呼ぶ（中間サーバなし）。キーは端末の安全領域に保存し、ログ・メモに残さない。
- オフライン時： ストック・見返しは可能。深掘りだけ「ネットが必要」と静かに表示。
